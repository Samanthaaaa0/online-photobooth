# 6-cut frames

Frame art for the 6-photo (2 x 3) strip. Any PNG in this folder shows up in the Editor
(name = file name, a leading `_` hides it).

Windows must stay exactly where the photos are: 6 windows of 579 x 492 px at x = 42 / 639 and
y = 96 / 606 / 1116 on a 1260 x 1794 image. The full guide, a generator and templates are in
`tools/frames/` (read `tools/frames/README.md`).

`button.png` and `polkadots.png` were built from the 4-cut art (same sprites and dot pattern).

# tools/

Helper scripts (Python 3 + `pip install numpy scipy pillow`). None of this runs in the website itself.

| folder | for |
|---|---|
| `stickers/` | cut stickers out of sticker-sheet pictures, rebuild the sticker list |
| `frames/` | make photo-strip frames, templates and the "how to design a frame" guide |
| `sheets/` | the sticker-sheet pictures the sticker script reads |
